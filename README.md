# 라벨링 스튜디오 (CVAT 스타일 데모)

브라우저만으로 실행되는 간단한 이미지 라벨링 웹앱입니다. 프로젝트 관리, 바운딩 박스 라벨링, COCO-SSD(TFJS) 기반 오토 라벨링, 사용자 제공 HTTP 엔드포인트/토큰 연동, SAM 엔드포인트 호출, JSON 내보내기를 지원합니다.

## 사용 방법
1. `index.html`을 브라우저에서 열면 바로 실행됩니다(로컬스토리지 사용).
2. 왼쪽에서 새 프로젝트를 만들고 라벨을 정의합니다.
3. 이미지를 업로드하면 중앙 패널에 썸네일이 표시됩니다.
4. 오른쪽 워크스페이스에서 레이블을 선택한 뒤 이미지를 드래그해 박스를 만듭니다.
5. **오토 라벨링** 버튼을 누르면 브라우저에서 로딩된 COCO-SSD 모델로 자동 박스를 생성하거나, 설정한 원격 엔드포인트로 요청합니다.
6. **SAM 추론** 버튼은 선택한 박스(없으면 중앙 영역)를 프롬프트로 사용해 설정한 SAM 엔드포인트로 박스를 요청합니다.
7. 완료되면 `JSON 내보내기`로 어노테이션을 저장하세요.

## 특징
- 프로젝트/라벨/이미지/어노테이션을 로컬스토리지에 자동 저장
- 캔버스 오버레이 기반 드로잉 및 선택 삭제
- 라벨 추가/삭제, 프로젝트 삭제, 데이터 초기화, JSON Export 기능
- 오토 라벨러/ SAM 엔드포인트 URL & 토큰 설정 카드 제공
- 반응형 레이아웃과 다크 UI
